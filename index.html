BookTimer 개인정보 처리방침

최종 수정일: 2026년 2월 9일

SimplyStrong Lab("당사")은 BookTimer 앱("앱")의 사용자 개인정보를 중요하게 생각합니다. 이 개인정보 처리방침은 앱이 수집, 사용, 보관하는 정보에 대해 설명합니다.

1. 수집하는 데이터

로컬 저장 데이터

앱은 다음 데이터를 사용자의 기기에 로컬로 저장합니다:

  • 등록한 책 정보 (제목, 저자, 표지 이미지 URL)
  • 독서 세션 기록 (시작 시간, 종료 시간, 소요 시간)
  • 독서 메모
  • 독서 목표 설정

이 데이터는 사용자의 기기에만 저장되며, 별도의 서버로 전송되지 않습니다.

iCloud 동기화

사용자가 iCloud 동기화를 활성화한 경우, 위 데이터가 Apple의 CloudKit 인프라를 통해 사용자의 다른 기기와 동기화됩니다. 이 데이터는 Apple의 개인정보 보호 정책에 따라 관리됩니다.

크래시 리포팅 (Sentry)

앱의 안정성을 개선하기 위해 Sentry를 통해 다음 정보를 수집합니다:

  • 크래시 로그 및 오류 정보
  • 기기 모델, OS 버전
  • 앱 버전

개인 식별 정보(PII)는 수집하지 않습니다.

사용 분석 (PostHog)

앱 개선을 위해 PostHog를 통해 익명의 사용 이벤트를 수집합니다:

  • 앱 기능 사용 현황 (책 추가, 타이머 사용, 목표 달성 등)
  • 기기 유형, OS 버전

개인 식별 정보(PII)는 수집하지 않으며, 모든 이벤트는 익명으로 처리됩니다.

2. 인앱 결제

BookTimer Pro 업그레이드는 Apple의 인앱 결제 시스템을 통해 처리됩니다. 당사는 결제 정보(신용카드 번호, 청구 주소 등)를 직접 수집하거나 저장하지 않습니다. 모든 결제는 Apple의 정책에 따라 처리됩니다.

3. 데이터 삭제

사용자는 앱 내 설정 > 데이터 관리에서 모든 독서 데이터를 삭제할 수 있습니다. 삭제된 데이터는 복구할 수 없습니다.

앱을 기기에서 삭제하면 로컬에 저장된 모든 데이터가 함께 삭제됩니다.

4. 추적 (Tracking)

BookTimer는 광고 목적의 사용자 추적을 하지 않습니다. ATT(App Tracking Transparency) 권한을 요청하지 않습니다.

5. 아동 개인정보

BookTimer는 만 14세 미만의 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

6. 개인정보 처리방침 변경

본 개인정보 처리방침은 변경될 수 있으며, 변경 시 앱 내 또는 이 페이지를 통해 공지합니다.
